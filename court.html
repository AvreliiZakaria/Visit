— На сайт
Бэкенд не отвечает Это статичная раздача (например GitHub Pages), а суду нужен сервер: база, аудио, жюри. Поднимается одной командой: cd server && npm install && npm run seed && npm start, затем открой localhost:8080/court.html. Разбор интерфейса без сервера лежит в прототипе.

Всё настоящее: запись идёт с микрофона, файлы лежат на сервере, голоса пишутся в базу. Кнопка голоса открывается, только когда сервер видит, что ты прослушал обе стороны на 80%.

Готов к записи 0:60

Браузер спросит доступ к микрофону. Запись обрывается на 60 секундах, меньше 10 секунд сервер не примет.

Телефоны, адреса и почты вырезаются автоматически, а дела с данными третьих лиц уходят на ручную проверку.
