# API «Вердикта»

База: `/api`. Формат JSON. Авторизация: `Authorization: Bearer <token>`.
Токен выдаётся анонимно, без почты и пароля.

Для тега `audio` токен можно передать в query (`?token=...`), потому что заголовки там задать нельзя.

---

## Аккаунт

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/auth/anon` | Анонимный аккаунт по `deviceId`. Повторный вызов с тем же устройством возвращает того же пользователя |
| GET | `/auth/me` | Профиль, счёт побед и поражений, бейджи, история споров |
| DELETE | `/me` | Обезличивает аккаунт (право на удаление данных) |

```bash
curl -X POST localhost:8080/api/auth/anon \
  -H 'Content-Type: application/json' \
  -d '{"deviceId":"my-browser-uuid"}'
```

## Споры

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/disputes` | Создаёт дело: `{ topic, consent }`. Тема проходит модерацию |
| POST | `/disputes/:id/sides/:label/audio` | Загружает запись (multipart: `audio`, `durationMs`, `transcript`). Меньше 10 секунд не принимается |
| GET | `/disputes/mine` | Мои дела |
| GET | `/disputes/:id` | Состояние дела. Счёт скрыт, пока нет вердикта |
| GET | `/disputes/by-code/:code` | Что видит человек по ссылке-приглашению |
| POST | `/disputes/by-code/:code/claim` | Занять сторону Б |
| POST | `/disputes/:id/publish-one-sided` | Оппонент молчит больше суток: опубликовать с пометкой |
| GET | `/disputes/audio/:sideId` | Запись. Доступна сторонам и присяжным с живым назначением |

Жизненный цикл: `draft` → `awaiting_opponent` → `in_jury` → `verdict`.
Отдельно `held` (ушло на ручную модерацию) и `closed`.

## Жюри

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/jury/next` | Выдаёт одно дело. `204`, если дел нет. Порядок сторон перемешан |
| POST | `/jury/:assignmentId/vote` | Голос: `{ side, listenedA, listenedB, comment }` |
| POST | `/jury/:assignmentId/skip` | Вернуть дело в очередь |

Сервер отклоняет голос, если:

- прослушано меньше 80% любой из сторон (`not_listened`);
- прошло меньше 15 секунд с момента выдачи дела (`too_fast`);
- с этого устройства в деле уже есть голос (`duplicate`);
- назначение истекло (`expired`) или дело закрыто (`closed`).

Ответ на голос не содержит счёта: иначе включается стадный эффект.

## Комментарии

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/comments/:disputeId` | Комментарии. Открываются вместе с вердиктом |
| POST | `/comments/:disputeId` | Написать. Можно только тем, кто голосовал |
| POST | `/comments/:commentId/upvote` | Плюс. Один раз, не себе |

## Модерация

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/reports` | Жалоба: `{ targetType, targetId, reason, note }`. Три жалобы прячут дело до разбора |
| GET | `/admin/queue` | Очередь на ручной разбор (заголовок `X-Admin-Token`) |
| POST | `/admin/disputes/:id/decision` | `{ action: approve или block }` |
| POST | `/admin/users/:id/ban` | `{ days, reason }` |

Автопроверка ловит телефоны, почты, адреса, документы, угрозы, упоминания несовершеннолетних
и ссылки на профили третьих лиц. Найденное либо уходит на ручной разбор, либо блокируется сразу.

## Деньги

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/billing/tiers` | Тарифы и цены |
| POST | `/billing/checkout` | `{ tier, disputeId }`. Провайдер заглушка: в мобилке это IAP, в вебе Stripe |
| POST | `/billing/webhook` | Точка входа для вебхука провайдера |

Тарифы: `free` (0 $), `urgent` (3 $, вердикт за 30 минут), `wide` (5 $, жюри до 1000), `sub` (7 $/мес).
Оплата меняет скорость сбора жюри и его размер, но никогда не результат.

## Движок вердиктов

Планировщик раз в 15 секунд закрывает дела, где:

- собран кворум (`votes >= jury_size`), либо
- вышел срок и голосов не меньше `MIN_QUORUM` (по умолчанию 20).

При закрытии считаются проценты, определяется победитель, проигравшему выдаётся бейдж на 30 дней,
неиспользованные назначения удаляются.
