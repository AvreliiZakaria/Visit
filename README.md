# Вердикт (Verdict)

Сайт продукта «Вердикт»: спор с партнёром или другом решает суд присяжных из ста незнакомцев.
Оба записывают по 60 секунд аргументов, жюри слушает обе стороны и голосует, вердикт приходит с процентами и топ-комментариями.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Лендинг: герой, как это работает, правила честности, тарифы, раздел для авторов, FAQ, запись в бету |
| `app.html` | Интерактивный прототип приложения: создание спора, приглашение оппонента, зал жюри, вердикт, профиль, пейволл |
| `assets/css/site.css` | Вся система стилей: токены, типографика, сетка, компоненты, адаптив |
| `assets/js/site.js` | Навигация, тикер дел, анимация вердикта, FAQ, форма записи |
| `.nojekyll` | Чтобы GitHub Pages отдавал файлы как есть |

Внешних зависимостей нет, кроме шрифтов Google Fonts и иконок Lucide с CDN. Сборка не нужна: это статика.

## Как открыть

Локально: просто открой `index.html` в браузере.

На GitHub Pages: `Settings` → `Pages` → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → `Save`.
Через минуту сайт будет тут: `https://avreliizakaria.github.io/visit/`

## Адаптив

Мобильный вперёд, интринсик-сайзинг вместо частокола брейкпоинтов. Ключевые точки: 640, 900, 1180.
На мобилке меняется не масштаб, а сама раскладка: навигация уезжает в выпадающее меню, герой становится вертикальным,
таблица тарифов превращается в список, тач-цели не меньше 44px.

## Форма записи в бету

Бэкенда нет, поэтому форма работает в двух режимах:

1. Если у `<form data-endpoint="...">` в `index.html` указан URL (например Formspree или свой обработчик), заявка уходит туда через `fetch`.
2. Если URL пустой, форма открывает почтовый клиент с готовым письмом. Так лендинг живой сразу, без сервера.

Чтобы подключить реальный сбор заявок, впиши свой endpoint в атрибут `data-endpoint` у формы `#waitlist`.

## Что это не делает

Это фронтенд. Настоящие записи аудио, база данных, распределение споров по жюри, платежи и модерация живут в бэкенде,
которого здесь нет. Прототип имитирует эти процессы на клиенте, чтобы можно было показывать людям и отдавать разработчику как спеку.

## Правила продукта, зашитые в интерфейс

- Присяжный не может голосовать, не прослушав обе стороны минимум на 80%.
- Текущий счёт скрыт до вердикта, иначе включается стадный эффект.
- Время вердикта не обещается, пока не собран кворум. Голоса не накручиваются.
- Спор попадает в контент только с явного согласия автора, оригинальный голос не публикуется.
